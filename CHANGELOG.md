# Public showcase changelog

## Firmware 1.2.8 — 27 September 2026

- The outlook temperature graph now shows each day's low-to-high range across the last 30 days plus today. The left labels are the coldest low and warmest high; days without a low use a short mark.
- Added a public preview of the 1.2.8 graph and clarified that the phone photos and clips document the earlier powered prototype rather than proving a 1.2.8 flash.

## Rev1.2 refresh — 27 September 2026

- Reworked the README around why I built Headway and the everyday use I imagine by the mirror, front door and desk.
- Added a responsive project page with switchable previews for all five looks and the train, bus, weather, outlook and setup screens. The setup portal is explained in short, readable cards.
- Replaced the old Rev7 and planned desk-case sections with current Model A Rev9 and Model B rev2 FreeCAD sources, print files and isometric/front/back/top/side views. Added a stand view for Model B and actual printer-bed photos, labelled as such.
- Added the nine-wire pinout map and links to the ESP32-C3 and MSP3218 technical documents.
- Recast the 0.75 W electricity figure as an assumption pending a meter check. At that assumption, continuous use is 6.57 kWh/year; example cost is €1.97/year at €0.30/kWh.
- Updated ownership, repository links and permission notices to the Headway name. Hardware compile, flash and fit checks are still open.

## Firmware 1.2.7 — 27 September 2026

The three-hour train delay history now survives a software restart, with a gap for time spent restarting or in setup. Power removal and Start over clear it. The current firmware, tests and detailed changes are in [Headway_code](https://github.com/haldarsaurav/Headway_code).

## Rev1.1 — 25 September 2026

The feature and icon guide, corrected delay-history definition and reliability review were completed. The old release tags remain in the code repository's history.
